# Card Bot — Daily Scouting Board

**Status: NOT YET UPDATED BY A LIVE SCAN**

This page will update automatically when the scheduled GitHub Actions paper bot runs on the default branch.

It will show:
- Every player returned by the existing live MLB top-15 scanner, including deal and breakout scores and the raw skill-change explanation.
- Each Bowman 1st auto / rookie auto reference card checked, recent sold-comps pricing, and why it qualified or was rejected.
- Any paper purchases, holdings, cash left from the initial USD 100 bankroll, and estimated net liquidation after fees.
- Missing-data notices rather than fabricated prices or fake transactions.

The daily workflow can also be run manually in GitHub Actions. After it runs, refresh this page to see the current scouting board.

**Note:** This is a paper simulation using broad reference-card sold-price medians, not an exact available eBay item or a real purchase. The current scanner is MLB only. A missing or blank report does not mean the wider sports-card market was completely searched.
